The AI/self-worth artwork was generated on 2026-10-13 (Asia/Tehran). Mehdi
selected the first concept, “آدم و سیل”, and explicitly authorized its use for
both article editions. It uses the same black ink/off-white/brick visual
language. The source is retained separately; the optimized derivative does
not change its composition. At the owner's request, the source background was
harmonized with the existing loop essay artwork before optimization.

The source files are 1254 × 1254 PNGs. The checked-in derivatives preserve
those dimensions as stripped WebP files at quality 88. They are editorial
artwork under `ADR-010`, not historical documents or reusable brand marks.
