## Z-index

```css
:root {
  --z-base: 0;
  --z-header: 10;
  --z-popover: 20;
  --z-dialog: 30;
}
```

Values outside this scale are prohibited without an architectural explanation.

## Breakpoints

Breakpoints should live near their components in CSS and respond to content breakage. Guidance:

```text
compact  < 40rem
medium   40rem–64rem
wide     > 64rem
```

## Icon and Graphic

```text
icon sizes: 16 / 20 / 24px
default stroke: 1.5px
SVG line: 1px
SVG node: 4 / 6 / 8px
header brand-mark block size: 30–34px compact / 36–40px wide
```

Official social brand marks render at 20px with `--color-brand-monochrome`. Their
published shape and approved black color must not be modified; blog-theme
alignment comes from surrounding spacing, typography and canvas rather than
recoloring the marks.

The historical creature derivative must use the existing semantic palette. A
new sepia or gold brand palette is prohibited. Small-size derivatives may
increase ink coverage and remove interior detail for legibility without adding
a new color token.

## Localization Tokens

```css
html[lang="fa"] {
  --reading-max: var(--reading-max-fa);
}

html[lang="en"] {
  --reading-max: var(--reading-max-en);
}

.code,
pre,
code,
[data-bidi="ltr"] {
  direction: ltr;
  unicode-bidi: isolate;
  text-align: left;
}
```

## Token Governance

- Repeating raw values in components is prohibited.
- New tokens must be semantic, not color-named values such as `--red-2`.
- Token removal or modification must be checked through FA/EN visual regression.
- Dark mode must not be added until its full palette is defined and approved by the product owner.
