# ADR-005 — Subtle Iranian Identity and Software-native Graphics

| Field | Value |
|---|---|
| Status | `accepted` |
| Date | 2026-07-29 |
| Owner | Mehdi Ahmadirad |
| Affects | `SPEC-002`, `SPEC-006` |

## Context

Iranian identity should be part of design grammar, not a decorative image. The metaphor of building architecture for software architecture is also rejected.

## Decision

Iranian identity comes from the quality of Persian typography, localized numerals and dates, geometric proportions, grids, rhythm, repetition and a brick/lapis palette. Identity-defining graphics use SVG and the vocabulary of node, edge, dependency, module, boundary, state and flow.

## Prohibited

Photos or sketches of buildings, mosques, domes, Persepolis, ready-made tilework, attached shamsa or arabesque motifs, dominant turquoise, pseudo-calligraphic UI and technology stock imagery.

## Consequences

The architectural images in the reference only define the position and weight of the composition. Agent should replace the subject, not recreate the same illustration.
